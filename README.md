# MedTerm Content Skill

**اسکیل تولید محتوای آموزشی اصطلاحات پزشکی با هوش مصنوعی**

این مخزن یک «اسکیل» است: مجموعه‌ای از دستورالعمل، قواعد، داده و ابزار که هر مدل هوش مصنوعی (Claude، ChatGPT، DeepSeek و...) با خواندن آن یاد می‌گیرد اصطلاحات پزشکی را **دقیقاً طبق استاندارد محتوای پروژه** پیش‌نویس کند.

خروجی آن سطرهای آماده برای فایل اکسل ورود انبوه پنل مدیریت است، همراه با علامت‌گذاری مواردی که بازبین باید با دقت بیشتری بررسی کند.

> **مهم:** هر چیزی که این اسکیل تولید می‌کند **پیش‌نویس** است. هیچ اصطلاحی بدون تأیید بازبین پزشکی و بازبین زبان منتشر نمی‌شود.

---

## چه چیزی را پوشش می‌دهد؟

نسخه اول:

- **اصطلاح پزشکی** (مثل tachycardia)
- **جزء واژه:** پیشوند (tachy-)، ریشه (cardi/o)، پسوند (-itis)
- **اختصار** (مثل BP)

سؤال و درس کامل در نسخه بعد اضافه می‌شوند.

## روش استفاده در هر محیط

### Claude

1. کل پوشه `medterm-content-skill` را به‌صورت فایل ZIP دانلود کنید.
2. در Claude به **Settings → Capabilities → Skills** بروید و فایل ZIP را بارگذاری کنید.
3. از این به بعد کافی است بنویسید: «اصطلاحات ماژول ۳ را با اسکیل MedTerm بساز». Claude اسکیل را خودکار فعال می‌کند و می‌تواند بررسی‌کننده را هم اجرا کند.

### ChatGPT

**روش پیشنهادی، یک GPT اختصاصی:**
1. در ChatGPT یک GPT جدید بسازید (Explore GPTs → Create).
2. در بخش Instructions بنویسید: «طبق فایل SKILL.md در دانش خودت کار کن و با نویسنده فارسی صحبت کن.»
3. همه فایل‌های پوشه‌های `reference`، `data` و `scripts` و فایل `SKILL.md` را در بخش Knowledge بارگذاری کنید.
4. قابلیت **Code Interpreter** را روشن کنید تا بررسی‌کننده اجرا شود.

**روش سریع:** در یک چت معمولی، لینک خام فایل `START.md` را بدهید و بگویید «طبق این فایل کار کن»:

```
https://raw.githubusercontent.com/OWNER/medterm-content-skill/main/START.md
```

### DeepSeek

DeepSeek لینک‌ها را همیشه نمی‌خواند و کد اجرا نمی‌کند. پس:

1. فایل `START.md` را دانلود کنید.
2. آن را در چت **پیوست** کنید (یا محتوایش را کپی کنید).
3. بنویسید: «طبق این فایل کار کن.»

بررسی خودکار در این حالت انجام نمی‌شود، ولی پنل مدیریت هنگام ورود انبوه همه قواعد را دوباره بررسی می‌کند.

## روند کار نویسنده

1. درخواست بدهید، مثلاً: «برای ماژول ۳، اصطلاحات hyper- و hypo- مربوط به قند و فشار خون را بساز.»
2. مدل از اجزای واژه و واژه‌نامه موجود استفاده می‌کند و پیش‌نویس را می‌سازد.
3. مدل یک بلوک CSV و جدول علامت‌های بازبینی تحویل می‌دهد.
4. CSV را در اکسل ورود انبوه کپی کنید (یا فایل اکسلی که مدل ساخته را بردارید).
5. فایل را برای بازبینی پزشکی و زبانی بفرستید.

## بررسی‌کننده خودکار

اگر Python دارید، خودتان هم می‌توانید هر فایلی را بررسی کنید:

```bash
python scripts/validate.py my_items.csv
```

```bash
python scripts/to_excel.py my_items.csv my_items.xlsx
```

اگر پیش‌نویس را به شکل JSON دارید (روش پیشنهادی برای جلوگیری از جابه‌جایی ستون‌ها)، اول آن را به CSV تبدیل کنید:

```bash
python scripts/json_to_csv.py my_items.json my_items.csv
```

برای ساختن صفحه فارسی بازبینی (مناسب ارسال برای بازبین‌ها):

```bash
python scripts/report_html.py my_items.csv review.html
```

بررسی‌کننده این موارد را کنترل می‌کند: تعداد ستون‌های هر ردیف، قالب شناسه، شکل پیشوند و پسوند، آوانگاری و تکیه، حروف عربی در متن فارسی، متن فارسی در ستون‌های انگلیسی، طول تعریف و جمله مثال، تکرار نشدن اصطلاح در تعریف، وجود اجزای واژه و تطابقشان با املای اصطلاح، یکسانی معادل فارسی در ترجمه مثال، مقادیر مجاز دسته و سطح، و خالی بودن ستون‌های بازبین.

برچسب‌های بازبینی را هم خودکار اضافه می‌کند: آوانگاری، معادل فارسی تأییدنشده، اعداد بالینی (رقمی یا حرفی) و ادعاهای بالینی در جمله مثال.

## ساختار مخزن

| مسیر | محتوا |
| --- | --- |
| `SKILL.md` | نقطه شروع اسکیل برای مدل |
| `START.md` | نسخه تک‌فایلی برای DeepSeek و چت‌های بدون اسکیل (ساخته‌شده خودکار) |
| `reference/` | راهنمای نگارش، ستون‌ها و مقادیر مجاز، نمونه‌ها |
| `data/word_parts.csv` | فهرست اجزای واژه موجود |
| `data/glossary_fa.csv` | واژه‌نامه مشترک معادل‌های فارسی |
| `scripts/` | بررسی‌کننده، تبدیل به اکسل، ساخت START.md |
| `examples/` | نمونه درست و نمونه پرخطا |

## مشارکت

- برای افزودن جزء واژه یا معادل فارسی، فایل‌های `data/` را ویرایش کنید. **هر تغییری باید پیش از ادغام به تأیید بازبین پزشکی برسد.**
- پس از ویرایش هر فایل در `SKILL.md`، `reference/` یا `data/`، این دستور را اجرا کنید تا `START.md` به‌روز شود:

```bash
python scripts/build_start.py
```

- هرگز متن کتاب‌های درسی یا فرهنگ‌های پولی را وارد مخزن نکنید.

## وضعیت داده‌ها

فهرست اجزای واژه (۷۴ مورد) و واژه‌نامه (۲۴ مورد) **نسخه اولیه** هستند و هنوز بازبینی پزشکی نشده‌اند. وضعیت هر سطر در ستون `status` ثبت است. وقتی بازبین یک سطر را تأیید کرد، مقدار آن را `approved` کنید؛ از آن به بعد معادل‌های فارسی تأییدشده دیگر برچسب بازبینی نمی‌گیرند.

## English summary

A portable "skill" that teaches any AI model (Claude, ChatGPT, DeepSeek, …) to draft medical-terminology learning items (terms, word parts, abbreviations) for a Persian–English medical English app, following a strict content style guide. Output is import-ready CSV with review flags; every item still requires human medical and language review. Use the folder as a Claude Skill, upload it as ChatGPT GPT knowledge, or give any chat the single-file `START.md`. Code: MIT. Content and data: CC BY 4.0.
